# Manuscript

`chronoflow.tex` compiles with any TeX Live ≥ 2022 (pdflatex/xelatex) or with Tectonic:

```bash
tectonic -X compile chronoflow.tex        # or: latexmk -pdf chronoflow.tex
```

Packages: geometry, graphicx, amsmath, booktabs, siunitx (v3), microtype, hyperref, caption, authblk, natbib.
Figures are the composed PNGs in `figures/` (regenerated by `../analysis/make_panels.py`). The compiled `chronoflow.pdf` is included.
